# Learning notebooks

Open each `.ipynb` in Google Colab. These are exercise templates, **not** completed tutorial answers.

- `01-bigrams.ipynb`: Character vocabulary and count-based bigrams
- `02-neural-bigrams.ipynb`: Neural bigrams and gradients
- `03-embeddings-mlp.ipynb`: Embeddings and multilayer perceptrons
- `04-backpropagation.ipynb`: Backpropagation from first principles
- `05-training.ipynb`: Training, evaluation and reproducibility
- `06-transformers.ipynb`: From context windows to attention

Please work sequentially, but go back and revise explanations as needed. Keep generated samples small and record experiment settings.
